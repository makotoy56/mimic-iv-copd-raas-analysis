# 別実装による独立した Cox 計算（2026-11-18）

実データの非罰則 Cox モデル6種類・計40係数を、既存の lifelines と異なる統計実装 statsmodels `PHReg` 0.14.6 で再計算した。全モデルで、完全ケースの件数・死亡数・層数・係数名が現在の参照結果と一致し、対数係数・HR・95%信頼区間の両端・p値の絶対差が事前設定した `1e-4` 以内だった。

これは、認可済み環境で取得した実データに対する独立した統計実装による照合である。現在のポートフォリオが主張する検証範囲は[再現対象](REPRODUCIBLE_SCOPE.md)に示す。

## 実データの照合

承認済み BigQuery の既存テーブルを読み取り専用 SELECT で取得した。ドライラン推定・実処理は 2,736,972 bytes、課金対象は 20,971,520 bytes、ジョブ上限は 200,000,000 bytes。テーブルの再作成、課金・権限・保存設定の変更は行っていない。患者の識別子や個別日時は SELECT の出力に含めず、モデル行はメモリ内でのみ扱い、集計とモデル係数だけを保存した。外部解析サービスへの個票転送はない。

全体は11,964入院・1,692死亡。ACEi/ARB併用を除いたサブグループは11,951入院・1,690死亡。非罰則、Efron法、同じ完全ケース条件、同じ暦年群・追加層別条件で照合した。

全40係数について、対数係数の最大絶対差は `3.28488e-5`、HRは `2.30526e-5`、95%信頼区間の両端は `3.13221e-5`、p値は `3.75196e-5`。RAAS/ACEi/ARBの効果について、推定方向、95%信頼区間が1をまたぐか、p<0.05かという判定は現在の参照結果と同じだった。収束警告は検出せず、スコアを入院数で割った最大絶対値が `1e-8` 以下であることも確認した。

データアクセス関数のみ既存コードを再利用し、カテゴリ作成・層の符号化・PHRegによる最適化・係数と標準誤差の計算は別途実装した。入力テーブルは共有しているため、これだけでソースSQLの独立抽出検証を行ったことにはならない。罰則モデル、PH診断、二次的logisticモデルは今回の実データ照合に含まれない。患者内相関、競合リスク、近似年齢、残余交絡に関する既存の制約も残る。
